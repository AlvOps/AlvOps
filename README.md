# AlvOps

Self-hosted first. Homelab plumbing, game tooling, and things built together with an AI agent
([Hermes](https://hermes-agent.nousresearch.com)).

## AI & agents

| Repo | What it does |
|---|---|
| [wow-mcp-forever](https://github.com/AlvOps/wow-mcp-forever) | MCP server that answers *World of Warcraft: Forever* questions from the Wowhead database — drops, vendors, quests, tooltips. No API keys. |
| [hermes-credits-plugin](https://github.com/AlvOps/hermes-credits-plugin) | OpenRouter credits chip + pane for the Hermes desktop app: balance, quota/budget bars, per-conversation call log. |

## Homelab

| Repo | What it does |
|---|---|
| [transmission-trackers](https://github.com/AlvOps/transmission-trackers) | Adds trackers from a list to every torrent in Transmission, automatically. |

## Game tooling

| Repo | What it does |
|---|---|
| [ffx-wayland-lightning-dodger-x2speed](https://github.com/AlvOps/ffx-wayland-lightning-dodger-x2speed) | Auto lightning dodger for Final Fantasy X HD Remaster on Linux/Wayland — raw pixel polling via `grim`, input through evdev, x2 game speed. |
| [regalos-mistria](https://github.com/AlvOps/regalos-mistria) | Gift finder for *Fields of Mistria* 1.0: type a villager and see what they love, like, dislike or hate — or search an item and see who wants it. 34 characters, 474 items, one page. |

## Small web things

| Repo | What it does |
|---|---|
| [twitch-folders](https://github.com/AlvOps/twitch-folders) | Organize the Twitch channels you follow into custom folders. |
| [grocery-shopping](https://github.com/AlvOps/grocery-shopping) | Grocery list that lives in your device — no account, no server. |
